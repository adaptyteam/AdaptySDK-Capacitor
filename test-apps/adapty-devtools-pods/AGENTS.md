# CLAUDE.md

This file provides guidance to LLM when working with code in this folder.

Read [README.md](README.md) first: what this app is for and why it has no code of its own. Everything
about the app itself — architecture, element ids, credentials, driving it — is in
[`examples/adapty-devtools/AGENTS.md`](../../examples/adapty-devtools/AGENTS.md).

## Rules

- **Never add app code here.** `src` is a symlink to `examples/adapty-devtools/src`; edit there.
  Anything that has to differ belongs in this folder's configs, not in a copy of the sources.
- `vite.config.ts` and `tsconfig.json` set `preserveSymlinks`, so imports inside the linked `src`
  resolve from THIS app: its `node_modules` and its `.adapty-credentials.json`. Without it they would
  resolve from the devtools' folder, and the native plugins `cap sync` installs from here would no
  longer match the JS that runs. `build.outDir` is absolute for the same reason.
- `tsconfig.json` extends the devtools' one. `yarn wvd` runs the devtools' CLI with
  `WVD_APP_ROOT=.`, so it reads `appId` / `appName` from this app's `capacitor.config.json`.
- The Xcode project references the resources (`assets/ios/*`, `AdaptyDemoApp.storekit`) in
  `examples/adapty-devtools` by relative path; there are no copies to keep in sync.

## CocoaPods

`ios/` was generated by `npx cap add ios --packagemanager CocoaPods` with the devtools' Capacitor CLI
(8.0.1), then given the devtools' display name and resources and its shared `App` scheme.
`CAPACITOR_DEBUG` / `debug.xcconfig` is not carried over: it exists only for Capacitor's prebuilt SPM
binary, and the pods compile with `#if DEBUG`, which keeps the WebView inspectable for `yarn wvd`.

`ios/App/Podfile` loads the plugin's Podfile helpers exactly as a consumer does (README "CocoaPods"
of `@adapty/capacitor`): through `node require.resolve` — `cap sync` drops a `require_relative`
placed above Capacitor's own — then `adapty_pods!` for the Adapty pods from the spec repo, and
`adapty_enable_kids_mode(installer)` behind `ADAPTY_KIDS_MODE=1`. `cap sync` rewrites only
`def capacitor_pods` and the pods_helpers require; keep edits outside them. `Podfile.lock` is
committed. The bundle id placeholder `com.example.plugin.pods` lets this app sit next to the SPM
devtools on one simulator; `yarn credentials` replaces it.
